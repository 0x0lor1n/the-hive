zsh — key and tool reference

elster · source of truth: cells/deck/homeModules/{zsh,skim,fzf,bat,eza,zoxide,git,direnv}.nix, dotfiles/zsh/{key-bindings,functions,config}.zsh

The line editor is zsh-vi-mode: every prompt starts in insert mode (beam cursor); Esc goes to normal mode (block cursor), i / a back to insert.
Ctrl chords below are insert-mode bindings. Anything with Super goes to dwl, Ctrl+Shift and Alt+1..9 go to tmux (see the dwl + tmux sheet).
Plugins: zsh-vi-mode · zsh-autocomplete · zsh-autosuggestions · fast-syntax-highlighting · zsh-histdb + histdb-skim · skim · zsh-nix-shell · powerlevel10k.

editing · vi mode

Escnormal mode (no delay: ZVM_ESCAPE_KEYTIMEOUT=0)
i / a / I / Ainsert here / after cursor / at line start / at line end
v / Vvisual / visual-line selection (white on black)
vvnormal mode: edit the command line in $EDITOR (nvim)
u / Ctrl+R (normal)undo / redo
sa motion charsurround: add, e.g. saiw" wraps the word in quotes (s-prefix scheme)
sd char · sr old newsurround: delete / replace, e.g. sd", sr"'
Ctrl+A / Ctrl+Einsert mode: line start / line end
Ctrl+W / Ctrl+Uinsert mode: delete word back / delete to line start
Ctrl+Ycopy the whole command line to the clipboard (copybuffer → clipcopy)
→ (at end of line)accept the grey autosuggestion; anywhere else it just moves the cursor

Autosuggestions (ghost text) come from history first, then completion; they switch off once the buffer is longer than 20 characters. Pasted text is shown bold, no background.

completion menu · Tab

typingzsh-autocomplete lists matches automatically after 2 characters (0.1 s delay); fuzzy, spelling-corrected and approximate matches included; dotfiles always shown
Tabenter the menu (menu-select); inside: next item
Shift+Tabenter the menu; inside: previous item
↑ ↓ ← →move in the menu
Ctrl+\type-to-filter inside the menu (menu-search)
Ctrl+Yaccept the highlighted item and leave the menu
Enteraccept and run the command
Ctrl+E / Backspaceundo the completion and leave the menu
Escabort the menu
**Tabskim fuzzy completion, e.g. nvim **, cd **, kill -9 **, ssh **, unset **

history · Ctrl+R

Ctrl+Rfuzzy history search over the sqlite history (histdb-skim); opens on the Directory tab
F1 / F2 / F3 / F4tab: this Session / this Directory / this Host / Everywhere
Ctrl+R (inside)cycle the tabs Session → Directory → Host → Everywhere
F5toggle grouping of identical commands
F6 / F7lock the results to the selected entry's session / directory (press again to unlock)
Enter · Esc / Ctrl+Cput the command on the line (not executed) · abort
↑ / ↓plain history walk at the prompt
histdb patternquery history from the shell; --in DIR, --host, --from '1 week ago', -d details, --limit N
histdb-top · histdb-top-heremost used commands, overall / in this directory
sqlite3 $HISTDB_FILEraw access: ~/.local/share/zsh/history.db (survives the impermanence rollback)

Not recorded: rm …, rmd …, git s, git unstash, git stash…. Duplicates are collapsed, blanks trimmed. Plain $HISTFILE is kept too (1 000 000 lines) — ↑ uses it.

fuzzy finder · skim

Ctrl+Tpick a file under the cwd (fd, hidden files included, .git skipped; bat preview) → path inserted at the cursor
Alt+Cpick a directory (eza tree preview) → cd into it
Tab (inside)multi-select
Ctrl+J / Ctrl+K · ↑ / ↓move
Enter · Escaccept · abort
skthe binary itself: rg -n foo | sk, fd | sk -m

fzf is installed for tools that shell out to it (sesh, lazygit …) but has no shell bindings. Inside fzf popups: Ctrl+Y accept, Ctrl+E abort, Ctrl+F/Ctrl+B half page, Ctrl+D/Ctrl+U scroll preview, ? toggle preview.

shell options worth knowing

INTERACTIVE_COMMENTS# comment works at the prompt — handy to park a half-typed command in history
HASH_EXECUTABLES_ONLYcommand hash only trusts real executables; rehash after installing something
NUMERIC_GLOB_SORT*.log sorts file1 file2 file10, not file1 file10 file2
GLOB_DOTSglobs and completion match dotfiles without a leading .
