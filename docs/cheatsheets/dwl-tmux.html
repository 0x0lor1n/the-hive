dwl + tmux — key reference

elster · source of truth: packages/dwl/config.h, dotfiles/tmux/config.conf

Super = Win/Logo key — everything with Super goes to dwl (the compositor).
Ctrl / Ctrl+Shift / Alt chords without Super go to tmux (no prefix needed). The tmux prefix is Ctrl+Shift+B; it is only needed for the few prefix … bindings.
Every foot window is a tmux client, so "terminal" below means foot + tmux.

dwl · launching

Super+Alt+Tnew terminal window (foot + tmux), or focus the open one (tag 1)
Super+Alt+Hagents: foot + herdr, or focus the open one (tag 2) — keys in the last section
Super+D / Super+Papp launcher (fuzzel)
Super+Alt+Ffile manager (thunar)
Super+Ccalculator (fuzzel; result goes to the clipboard)
Super+Vclipboard history (cliphist)
Super+Alt+Wwifi menu (nmcli via fuzzel)
Super+Escpower menu
Super+Llock screen (swaylock)
Super+Shift+Qquit dwl
Ctrl+Alt+F7..F12switch virtual terminal

dwl · windows and focus

Super+J / Super+Kfocus next / previous window in the stack
Super+Shift+J / Super+Shift+Kmove window down / up the stack
Super+Enterzoom — make the focused window the master (swap with master)
Super+Shift+Cclose window
Super+Etoggle fullscreen
Super+Shift+Spacetoggle floating
Super+Tabback to the previously viewed tags (toggle back and forth)
Super+Left mousedrag window
Super+Middle mousetoggle floating
Super+Right mouseresize window

Focus does not follow the mouse (sloppyfocus = 0): it changes on click or Super+J/K only. Touchpad taps click but never drag.

dwl · two monitors

Super+, / Super+.focus the left / right monitor
Super+Shift+< / Super+Shift+>send window to the left / right monitor

Each monitor has its own set of tags. Super+1..9 switches tags on the monitor that has focus; the bar on each monitor shows that monitor's tags.

dwl · tags 1..9 (workspaces)

Super+1..9view tag N
Super+Ctrl+1..9also view tag N (several tags at once)
Super+Shift+1..9move window to tag N
Super+Ctrl+Shift+1..9window also visible on tag N (toggle)
Super+0view all tags
Super+Shift+0window on all tags

A tag is not a workspace in the strict sense: a window can live on several tags and a monitor can show several tags at once. In the bar: the viewed tag is highlighted, occupied tags are bright, empty ones are dimmed, urgent ones red.

dwl · layouts

Super+Ttile []= — auto: landscape monitor → master left, stack right; portrait monitor → master on top, stack below
Super+Ffloating ><>
Super+Mmonocle [M] (one window at a time)
Super+Spaceswitch between the two most recent layouts
Super+I+1 window in the master area
Super+Shift+D−1 window in the master area
Super+H / Super+Shift+Lmaster area smaller / larger (±5%)

Layout mode: Super+R, then keys without Super, Esc to leave

A layout badge appears at the left of the bar while the mode is active. Keys not listed here do nothing until you leave the mode.

← / →+1 / −1 window in the master area (stays in the mode — press repeatedly)
Shift+← / Shift+→master area smaller / larger (stays in the mode)
t / f / mtile (auto by monitor shape) / floating / monocle — leaves the mode
bbstack TTT — force master on top, stack below — leaves the mode
Shift+Ftoggle floating on the focused window — leaves the mode
Escleave the mode

Typical: Super+R, Shift+→ ×3, Esc.

dwl · screenshots and recording

Printwhole screen → clipboard
Super+Printtakeshot: whole screen → file + clipboard + notification
Super+Alt+Stakeshot: select area (slurp) → file + clipboard + notification
Super+Shift+Sselect area → clipboard only (no file)
Super+Alt+Rrecorder: select area → mp4. Press again, or click REC in the bar, to stop

From the takeshot notification: Edit (satty — arrows, lines, text, pixelate, blur) / Open / Copy PNG. Files land in ~/Pictures/Screenshots and ~/Videos/Recordings.

dwl · notifications (mako)

Notification mode: Super+Alt+N, then one key

hshow the last dismissed notification
ainvoke the notification's default action
cdismiss one
Shift+Cdismiss all

All of these are one-shot: they return to normal mode immediately.

tmux · panes

Ctrl+Shift+Enternew pane (split). Super+Shift+Enter does the same — dwl passes it through
Ctrl+Shift+Wclose pane (layout re-applied)
Ctrl+← Ctrl+↑ Ctrl+↓ Ctrl+→focus the pane in that direction
Ctrl+N / Ctrl+Pnext / previous pane (passed to vim / fzf when they are running)
Ctrl+Shift+N / Ctrl+Shift+Pswap pane with the next / previous one
Ctrl+Enterswap pane into the master slot (top-left)
Ctrl+Shift+←↑↓→resize pane by 4 cells
Ctrl+Shift+Fzoom pane to the whole window / back
Ctrl+Alt+Enterbreak pane out into its own window
Ctrl+Alt+Gsplit with a shell behind proxychains (ghost@ prompt)
Ctrl+F4show pane numbers
Ctrl+Shift+F4show pane numbers, then press one to swap with it
prefix pfuzzy pane picker with preview (sk)
prefix y / Ysynchronised input to all panes on / off

Layout mode: Ctrl+Shift+L, then one key

vmain-vertical — master left, stack right
hmain-horizontal — master on top, stack below
ttiled — equal grid
fzoom pane

After every split tmux picks the layout from the window shape, same rule as dwl's tile: wide window → main-vertical, tall (portrait monitor) window → main-horizontal. The keys above override it for the current window.

tmux · windows and sessions

Ctrl+Shift+Tnew window (inserted after the current one, same directory)
Ctrl+Shift+Qclose window (asks for confirmation if it has more than one pane)
Alt+1..9go to window N
Ctrl+, / Ctrl+.previous / next window
Ctrl+Shift+< / Ctrl+Shift+>move window left / right
prefix ssession picker (sesh). Inside: Tab/Shift+Tab move, Ctrl+A all, Ctrl+T tmux only, Ctrl+G configs, Ctrl+X zoxide dirs, Ctrl+F find dir, Ctrl+D kill session
prefix Llast session

tmux · scrollback and copy

Ctrl+Shift+PgUp / PgDnscroll history one page (passed to vim / less when running)
Ctrl+Shift+Home / Endjump to top / bottom of history
Ctrl+Shift+Kclear screen and history
vcopy-mode: start selection
Ctrl+Vcopy-mode: toggle rectangle selection
ycopy-mode: copy and leave
Ctrl+Shift+F5reload tmux.conf

Copy mode uses vi keys (mode-keys vi). Mouse is off in tmux — select text with the keyboard.

herdr · agents (tag 2, Super+Alt+H) — same shape as tmux

Ctrl+Shift+Enterspawn agent: fuzzel asks kind (hermes / claude / opencode), then dir — first row is the focused pane's dir, then other panes, then zoxide. Enter-Enter = same agent, here
Ctrl+↑ / Ctrl+↓previous / next agent
Ctrl+← / Ctrl+→focus pane left / right inside the workspace
Ctrl+, / Ctrl+.previous / next workspace
Alt+1..9jump to workspace N
Ctrl+Shift+W / Ctrl+Shift+Qclose pane / close workspace
Ctrl+Shift+Fzoom pane / back
Ctrl+Shift+←↑↓→resize pane
Ctrl+Shift+Tnew tab
Ctrl+Shift+B -prefix + split (herdr default; Ctrl+N / Ctrl+P are prefixed too — inside the agents they are prompt history)
Shift+Enternewline in the hermes prompt (works under herdr via the HERDR_ENV patch, under tmux natively)
