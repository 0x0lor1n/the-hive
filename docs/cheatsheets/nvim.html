nvim — key reference

elster · LazyVim base + dotfiles/nvim/lua/custom/ (keymaps.lua, plugins/*.lua) · nvim 0.12

Space is leader (mapleader = " "). Space then wait 300 ms → which-key shows the menu; all ␣x below mean Space then x.
[n] normal · [i] insert · [v] visual · [x] visual/select · [o] operator-pending · [t] terminal · [c] command-line — bindings without a tag are normal mode.
Clipboard is unnamedplus (system clipboard) unless over SSH. Arrows move by display line (gj/gk) when there is no count.
