Firefox + Surfingkeys — key reference

elster · Firefox 154 (Phoenix policies) · source of truth: cells/workstation/profiles/browser-firefox.nix · Surfingkeys uses its default keymap (no custom settings in the repo)

Surfingkeys turns the page into a vim-like modal surface: single letters act while no text field is focused. Focused input → normal typing; Esc leaves it.
? shows the live, per-site list of Surfingkeys bindings — always authoritative. Alt+S disables Surfingkeys on the current site (toggle), Alt+I enters pass-through (keys go to the page until Esc), p passes through a single key.
Super chords belong to dwl. Inside Firefox Alt+1..9 and Ctrl+Shift+… are not stolen by tmux — they only go to tmux in a terminal.
