# Media stack: the in-app half

`media-download.nix` owns the services, datasets, firewall and Jellyfin's
`encoding.xml`. What the *arr / Prowlarr / qbittorrent / Jellyfin keep in
their own SQLite/XML is pushed by `configure.py`, which runs as the
`media-configure` oneshot after every deploy (and by hand: `media-configure`
on imladris). It is idempotent: resources are matched by name and PUT in
place, so editing the script and redeploying is the way to change a setting.

Nothing here is done in a web UI anymore. If a UI change is wanted, put it in
`configure.py`; the next run overwrites what it owns and leaves the rest.

## What it sets

| app | what |
|---|---|
| Jellyfin | startup wizard (ru/RU), libraries Фильмы/Сериалы/Аниме/Мультфильмы/Музыка, metrics off, viewer user (no admin, no delete, RU audio+subs), `arr-stack` API key |
| qbittorrent | categories `tv`/`movies`/`music` → `/tank/media/downloads/complete/<cat>` (paths/port/LAN auth bypass are the nix seed) |
| Sonarr | root `/tank/media/series`, qBittorrent client (cat `tv`), no rename, 755 folders, Jellyfin notification, tag `anime`, TRaSH CFs + `WEB-1080p RU` / `Anime RU` |
| Radarr | root `/tank/media/films`, client (cat `movies`), no rename, Jellyfin notification, TRaSH CFs + `UHD Bluray + WEB RU` / `HD Bluray + WEB RU` / `Anime RU` |
| Lidarr | root `/tank/media/music`, client (cat `music`), profile `FLAC > MP3-320` (cutoff Lossless), metadata Album+EP, track naming, cue/log/covers kept |
| Prowlarr | tag `cf` + FlareSolverr proxy; indexers RuTracker.org, Kinozal (both `cf`), RuTor, Nyaa.si, Anime Tosho; apps Sonarr/Radarr/Lidarr full sync with category lists |

TRaSH data comes from the `trash-guides` flake input (`cells/server/flake.nix`,
pinned by rev). Own additions: the `RU Audio` custom format (+2500, parsed
Russian OR dub keywords, NOT sub-only), `Dubs Only` neutralised, x265 softened.
Anime is a second Sonarr root (`/tank/media/anime`, `Anime RU` profile,
series type `anime`); the legacy trees were renamed to `Series (Year)/Season
01/Series S01Exx.mkv` with external `.ru.mka`/`.ru.ass` next to the video
(2026-10-21, log in `/tank/media/anime/.rename-log.tsv`). Cartoons are not a
separate library any more: feature films live in `films`, episodic ones in
`series`; the `Мультфильмы` Jellyfin library is removed by `configure.py`.

## Secrets

Tracker logins and the two Jellyfin passwords are colmena `deployment.keys`:
`secrets/imladris/{rutracker,kinozal,jellyfin-admin,jellyfin-tv}.age`, each a
`USERNAME=…\nPASSWORD=…` file encrypted to the workstation TPM identities and
the recovery key (same recipients as agenix). They land in `/run/credstore`
at deploy time and reach the oneshot via `ImportCredential`; a missing file
just skips that piece (Jellyfin wizard/users, the two private indexers).

```bash
# create / rotate; recipients = both TPM pubkeys + recovery, the age1… strings
# in secrets-agenix-zfs.nix (one -r each)
printf 'USERNAME=%s\nPASSWORD=%s\n' user pass | rage -e -r age1tag1… -r age1tag1… -r age12tng… -o secrets/imladris/rutracker.age
# read back
rage -d -i secrets/$(uname -n)-nix-rage.pub secrets/imladris/rutracker.age
```

The `arr-stack` Jellyfin API key is generated by Jellyfin itself and read back
over the API on every run; it is never stored in the repo.

```bash
media-configure                                                  # re-run, print the log

journalctl -u media-configure -o cat
```

## Vontar X5 (Android TV, 192.168.10.55)

    adb connect 192.168.10.55:5555
    adb install -r jellyfin-androidtv-v0.19.x-libre.apk   # from GitHub releases
    adb shell monkey -p org.jellyfin.androidtv 1

In the app: server `http://192.168.10.10:8096`, user `tv`. Playback →
*Exoplayer*, passthrough audio on. Also on the box (not ours): Kodi, NUM,
TorrServer client.
