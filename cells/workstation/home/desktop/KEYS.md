# dwl — памятка по клавишам (elster)

`Super` = Win/Logo. Источник истины — `packages/dwl/config.h`; этот файл
надо править вместе с ним.

## Запуск

| Клавиша | Что |
|---|---|
| `Super + Alt + T` | терминал (foot) |
| `Super + Shift + Enter` | терминал (foot) |
| `Super + D` / `Super + P` | лаунчер (fuzzel) |
| `Super + Alt + F` | файловый менеджер (thunar) |
| `Super + C` | калькулятор (fuzzel, результат в буфер) |
| `Super + V` | история буфера (cliphist) |
| `Super + Alt + W` | wifi-меню (nmcli через fuzzel) |
| `Super + Esc` | меню питания |
| `Super + L` | блокировка (swaylock) |

## Скриншоты / запись

| Клавиша | Что |
|---|---|
| `Print` | весь экран → буфер |
| `Super + Print` | takeshot: весь экран → файл + буфер + уведомление |
| `Super + Alt + S` | takeshot: область (slurp) → файл + буфер + уведомление |
| `Super + Shift + S` | область → только буфер (без файла) |
| `Super + Alt + R` | recorder: область → запись mp4. **Повторное нажатие или клик по `REC` в баре — стоп** |

Из уведомления takeshot: Edit (satty — стрелки, линии, текст, пиксели, blur) /
Open / Copy PNG. Файлы: `~/Pictures/Screenshots`, `~/Videos/Recordings`.

| `Super + Shift + J` / `K` | подвинуть окно по стеку |

## Лейауты (быстро, без режима)

| Клавиша | Что |
|---|---|
| `Super + T` | tile `[]=` |
| `Super + F` | floating `><>` |
| `Super + M` | monocle `[M]` |
| `Super + Space` | переключить между двумя последними лейаутами |
| `Super + I` | +1 окно в мастер-колонку |
| `Super + Shift + D` | −1 окно из мастер-колонки |
| `Super + H` / `Super + Shift + L` | мастер-колонка уже / шире (±5%) |

## Теги (воркспейсы) — 1..9

| Клавиша | Что |
|---|---|
| `Super + 1..9` | показать тег |
| `Super + Ctrl + 1..9` | показать тег **дополнительно** (несколько тегов сразу) |
| `Super + Shift + 1..9` | переместить окно на тег |
| `Super + Ctrl + Shift + 1..9` | окно видно **и** на этом теге (toggle) |
| `Super + 0` | показать все теги |
| `Super + Shift + 0` | окно на всех тегах |

Тег ≠ воркспейс в чистом виде: окно может висеть на нескольких тегах, а
экран — показывать несколько тегов одновременно. В баре: активный тег
подсвечен, занятые — жирные, пустые — приглушены.

## Режимы (modes-патч)

Префикс переводит dwl в режим; дальше клавиши жмутся **без Super**. В баре
слева появляется плашка `layout` / `notification`. `Esc` — выход. Клавиши,
не описанные в режиме, ничего не делают (в т.ч. обычные Super-хоткеи), пока
не вышел.

### `Super + R` → Layout

| Клавиша | Что | Выход из режима? |
|---|---|---|
| `←` / `→` | +1 / −1 окно в мастер-колонку | остаёшься — можно жать много раз |
| `Shift + ←` / `→` | мастер-колонка уже / шире (±5%) | остаёшься |
| `t` / `f` / `m` | tile / floating / monocle | сразу выход |
| `Shift + F` | float/unfloat текущего окна | сразу выход |
| `Esc` | выход | — |

Типичный сценарий: `Super+R`, `Shift+→` ×3, `Esc`.

### `Super + Alt + N` → Notification (mako)

| Клавиша | Что |
|---|---|
| `h` | показать последнее скрытое уведомление |
| `a` | нажать действие по умолчанию у уведомления |
| `c` | закрыть уведомление |
| `Shift + C` | закрыть все |

Все действия — one-shot, сразу возвращают в NORMAL.

|---|---|
| `Super + B` | показать/скрыть бар |
| клик `REC` | остановить запись |
| клик на колокольчик | toggle do-not-disturb (mako); ПКМ — закрыть все уведомления |

| громкость: клик / ПКМ / скролл | mute / pwvucontrol / громкость |
| яркость: скролл | яркость |
